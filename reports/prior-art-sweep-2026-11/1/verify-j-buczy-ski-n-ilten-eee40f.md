- **Accessible:** True

- **Passage:** φ is birational onto its image if and only if P(L) intersects only finitely

**Hypotheses.** Field: any algebraically closed K, so Q̄ fits. Dimension: X = P^1, L = O(3), d = 3, dim V = 4, M = span(1/b, u/b, ρ/(ub)), ℓ = 1, n = 2; 2ℓ < d holds. Lemmas 6.1-6.2 do not need n > 2 (Theorem 1.2 does). Conjugation: absent; the source has no u, ρ or relation p1p2 = ρp0². Genericity: Lemma 6.2 needs P(L) off X (M basepoint free). Here that always fails: the image is a conic, and 2m = 3 is impossible, so M has a base point.

**Explanation.** Lemmas 6.1(3) and 6.2 are at the cited place, as described. They give birationality of a basepoint-free projection of a smooth curve when 2ℓ < d − 2ρg. Nothing mentions progressions, 1, u, ρ/u, Möbius maps or the classification. My derivation, not the paper's: φ = (1 : u : ρ/u) factors through u, so birational means u is Möbius in h. But Lemma 6.2's hypothesis fails in every real instance, since parity excludes basepoint-free nets with conic image. So it only closes a vacuous branch, which the same parity count closes directly. The real case still needs its own argument: base point, dimension count forcing all quadrics, Veronese embedding. Those are exactly the target's degree count, and the source does not supply them. The final shapes u², ū², 1/(u−a) (normalising, partial fractions) are also absent. The lemma adds no substance; classical projection-of-twisted-cubic facts are the same level. Not a prior statement of the step; do not count it as a find.
